[ 02.1 // COMPONENTES ]

Componentes

Los componentes fundamentales de tu AGI: Hardware, Dataset, Red Neuronal, Algoritmo, además del comodín Quantum Core. Reúne cuatro sanos en tu rig para ganar.

[ 02.2 // AMENAZAS ]

Amenazas

Malware contra componentes rivales. Una amenaza infecta un componente; una segunda amenaza del mismo palo destruye la pila permanentemente.

[ 02.3 // DEFENSAS ]

Defensas

Contramedidas y escudos. Una defensa protege un componente absorbiendo la siguiente amenaza; una segunda defensa bloquea el componente permanentemente.

[ 02.4 // PROTOCOLOS ESPECIALES ]

Protocolos especiales

Programas de acción instantánea que reescriben el tablero: Data Heist, EMP Purge, System Override, Protocol Swap, Malware Migration y System Purge.

Sinergias tácticas

El mazo compartido de 54 cartas contiene componentes, amenazas, defensas y protocolos repartidos en cuatro palos distintos, además del comodín Quantum Core. Cada carta cumple una función táctica: los componentes impulsan tu condición de victoria, las amenazas sabotean el avance rival, las defensas blindan tu infraestructura y los protocolos causan interferencia en todo el tablero.

Bloqueo de un slot

Colocar dos defensas sobre un componente lo bloquea permanentemente. Un componente bloqueado es totalmente inmune a amenazas y solo puede cambiar de dueño mediante un System Override completo.

Curación y neutralización

Jugar una defensa sobre un componente infectado lo cura, descartando tanto la amenaza como la defensa. Jugar una amenaza sobre un componente protegido destruye el escudo, dejándolo vulnerable de nuevo.

Jugadas maestras con protocolos

Los protocolos provocan giros instantáneos en la mesa: usa Data Heist para robar un componente no bloqueado, EMP Purge para limpiar las manos rivales, o System Override para intercambiar rigs enteros cuando estés en desventaja.
